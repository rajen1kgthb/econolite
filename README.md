# Embedded CI/CD Pipeline (Cross-Compilation)

This project demonstrates an end-to-end CI/CD pipeline using Jenkins, Docker, and CMake with a PowerPC cross-compilation toolchain.

## Key Concepts
- Cross-compilation using custom toolchain
- CI/CD pipeline automation (Jenkinsfile)
- Containerized build environment (Docker)
- Build validation and artifact verification

## Purpose
Built to simulate real-world developer workflows and debugging scenarios, including:
- environment setup issues
- build/configuration failures
- pipeline-driven validation

## Tech Stack
- Jenkins
- Docker
- CMake
- C++
